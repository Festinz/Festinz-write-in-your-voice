# Papers, Theses And Reference Lists

Read this when the piece is a paper, thesis chapter, review, or any text with a reference list.

## 1. Structure

Use the structure the venue or guideline prescribes. Without one, the usual order for an empirical paper is:

| Part | What it has to do |
|---|---|
| Title | Name the object and the finding or method, without filler words. |
| Abstract | Problem, what was done, the main result with its number, what follows. No citations, no undefined abbreviations. Write it last. |
| Introduction | The problem, what is known, the gap, what this work does. End with the contribution stated plainly. |
| Methods | Enough for someone else to repeat the work: data, procedure, settings, software versions, how results were evaluated. |
| Results | What was found, in the order of the questions asked. Numbers with units and uncertainty. No interpretation beyond what a reader needs to follow a table. |
| Discussion | What the results mean, how they compare with prior work, limitations, what was not tested. |
| Conclusion | The answer to the question in the introduction, limited to what the results support. |
| References | Every cited source, in the required style. |

Write body sections as paragraphs. Keep one claim per paragraph and put the evidence in the same paragraph.

## 2. Finding Sources

- Search with the tools the agent actually has (web search, a scholarly database connector, the person's reference manager). Say which were used.
- Prefer the original paper, standard or dataset page over a blog or summary. Prefer the published version over a preprint when both exist, and cite the one that was read.
- Search for sources that disagree with the claim as well as ones that support it.
- Stop when the claim is supported. A reference list is not a measure of effort.

## 3. Verifying Every Reference

No reference goes into the list unless all of this is true:

1. The source exists: the DOI resolves, or the publisher or archive page was opened.
2. Title, authors, year, venue, volume and pages were copied from that page, not from memory.
3. The source says what the sentence citing it says. Open it and find the passage; for a number, find the table.
4. The person can get to it: record the DOI or URL.

Never produce a reference from memory alone. A plausible citation that was not checked is treated as a fabricated one: leave the claim uncited and tell the person it needs a source.

Keep a small table while working: claim, source, where in the source (page, section, figure), verified yes or no.

## 4. Using Sources In The Text

- Cite the specific point and connect it to this work in the same or the next sentence. Do not summarize a source for a paragraph.
- Paraphrase by default. Quote only wording that matters as wording, keep quotations short, and mark them as quotations with the page.
- Separate what the source found from what this work concludes from it.
- Unpublished material (course notes, internal documents, talks) is cited as such, with its title, author or organization, and date.

## 5. Citation Styles

Use the style the venue names and apply it to every entry the same way.

| Style | In text | List order |
|---|---|---|
| IEEE | `[3]` | by first appearance |
| APA 7 | `(Kim & Lee, 2023)` | alphabetical by first author |
| Vancouver | `(3)` or superscript | by first appearance |
| Chicago author-date | `(Kim and Lee 2023)` | alphabetical |

With a reference manager or BibTeX, keep one entry per source, a stable key, and the DOI field filled. Check the rendered list: capitalization of titles, journal abbreviations, page ranges with an en dash, no "et al." where the style lists all authors.

## 6. Final Checks For This Genre

1. Every in-text citation has a list entry and every list entry is cited.
2. Numbering or ordering follows the style.
3. Every entry passed section 3.
4. Figures and tables taken from other work carry their source and any permission the venue requires.
5. The abstract's numbers match the results section.
