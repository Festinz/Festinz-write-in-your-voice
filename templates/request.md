# Request template

Copy this, fill it in, and send it to your agent together with the files. Lines you leave empty are fine; the agent will ask or pick a default and tell you.

```text
Use the write-in-your-voice skill.

1. What to write:        (e.g. project report / proposal / reply to this email)
   Reader and purpose:   (e.g. my professor, graded / a hiring manager / a client)
   Language and length:  (e.g. English, max 5 pages)

2. AI rule here:         (allowed / not allowed / I don't know)

3. Format:               (attach the guideline, rubric or template; say the file type you need)

4. My voice:             (attach 2-3 texts I wrote myself, or my-voice.md, or say "use what you remember about my writing")

5. Material:             (attach data, results, code, notes, sources)

My own notes on what I want to say:
-
-
```

## 요청 양식 (한국어)

아래를 복사해 채운 뒤 파일과 함께 에이전트에게 보내세요. 비워 둔 항목은 에이전트가 묻거나 기본값을 정하고 알려 줍니다.

```text
write-in-your-voice 스킬을 써 줘.

1. 쓸 글:            (예: 프로젝트 보고서 / 제안서 / 이 메일에 대한 답장)
   읽는 사람과 목적:  (예: 교수님, 채점 대상 / 채용 담당자 / 거래처)
   언어와 분량:      (예: 한국어, 5쪽 이내)

2. AI 사용 규정:     (허용 / 금지 / 모름)

3. 양식:            (가이드라인·채점기준·템플릿 첨부, 필요한 파일 형식)

4. 내 문체:          (내가 직접 쓴 글 2~3편 첨부, 또는 my-voice.md, 또는 "내 글쓰기에 대해 기억하는 것을 써 줘")

5. 자료:            (데이터, 결과, 코드, 메모, 출처 첨부)

내가 하고 싶은 말 메모:
-
-
```
